# DevConf 2026

DevConf 2026 is a responsive developer conference landing page built as
part of Programming Hero Assignment-001. The page presents a modern
conference experience with a navigation bar, hero banner, speaker cards,
pricing plans, AI-assisted conference schedule highlights, and a footer.

## 🚀 Live Demo

[View Live Project](https://im-asam.github.io/assignment01)

## 📦 GitHub Repository

[View Source Code](https://github.com/im-asam/assignment01)

## ✨ Features

-   Responsive DevConf 2026 landing page
-   Navigation bar with conference menu items and Register Now button
-   Hero section with conference introduction and call-to-action
-   Meet the Speakers section with four speaker cards
-   Speaker category, name, and company information
-   Three pricing plans: Standard, Pro, and Team
-   Highlighted Pro pricing plan
-   Conference Schedule Highlights section with four sessions
-   Footer with DevConf branding and social media icons
-   Dark conference-themed schedule and footer sections
-   Responsive layout for different screen sizes

## 🛠️ Technologies Used

-   HTML5
-   CSS3
-   Google Fonts
-   Font Awesome

No JavaScript or CSS framework was used.

## 🤖 AI Challenge

The custom section for the AI Challenge is **Conference Schedule
Highlights**.

It presents four Day 1 featured sessions:

-   Opening Keynote: The AI Era
-   The Future of AI Integration
-   Next-Gen Frontend Architecture
-   Security Deep Dive

AI was used to ideate and refine the schedule section into a card-based
layout suitable for the conference landing page.

The prompts used for the AI Challenge are included in
[`prompts.md`](./prompts.md).
